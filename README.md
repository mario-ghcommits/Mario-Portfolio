# Mario Lin — Always building.

A responsive portfolio built with React, Vite, and the MIT-licensed ThreeUI OrbitalSphereBackground component.

## Development

```sh
pnpm install
pnpm dev
```

## Production

```sh
pnpm build
```

Vercel settings: Vite preset, output `dist`, production branch `main`.

Edit `src/main.jsx` for biography and achievements. The city illustration is conceptual, not a photograph of the competition model. Expected education and volunteer dates reflect LinkedIn as of October 2026.

Features: responsive design, animated 3D sphere, scroll reveals, motion toggle, reduced-motion support, keyboard-accessible project dialog, and LinkedIn contact links.
