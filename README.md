# Mario Lin — Always building.

A responsive portfolio highlighting Mario Lin’s projects, engineering interests, education, and community involvement, based on his LinkedIn profile.

## Stack
React 19, Vite 7, and the MIT-licensed ThreeUI OrbitalSphereBackground component. Includes a motion toggle, reduced-motion preference support, keyboard-accessible project dialog, responsive layout, and conceptual city illustration.

## Develop
```sh
pnpm install
pnpm dev
```

## Build
```sh
pnpm build
```
Vercel: Vite preset, build command `pnpm build`, output directory `dist`, production branch `main`.

## Content
Edit `src/main.jsx` to update biography, achievements, or education. The Auquara city illustration is conceptual and is not a photo of the competition model. Education graduation dates are expected. Volunteer dates reflect the term listed on LinkedIn as of October 2026.
